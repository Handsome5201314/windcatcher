# 分割修正与隔离评测

## 工作台入口

选择已分割病例，在 CT 区域下方展开 **分割改进 · 修正记录与试算**。

1. 在现有编辑器修正主鼻腔掩膜，或导入修正掩膜。保存事务同时记录修正前后快照。首次启用之前的历史编辑不补造记录；没有实际体素变化的保存不生成样本。
2. 面板显示版本、补回/删除体素数量及参考状态。自动去外部空气、撤销、重置也是待核对的变更，不自动成为正确标签。
3. 当前掩膜已经人工对照 CT 核对、用途授权确认后，可显式登记参考。匿名患者分组采用 `subject-001` 一类编号；同一患者不同 CT 必须使用相同分组。病例内不同样本不允许使用不同分组。
4. 选择策略，点击 **试算并对照**。无参考时只报告改动数量；有参考时报告实际漏分、误分、通道分断和物理边界误差。正式掩膜、端面、CFD 状态不被候选计算修改。

当前策略仅有原版本和两档去除小孤立组件的试验策略。它们是完整评测链路的基线，不是新训练的鼻腔分割模型；无法恢复先前被包络误删的鼻孔。连通组件与边界指标也不能替代关键解剖区域的独立审核。

## 数据与权限

- 本机私有目录：`cases/<匿名编号>/learning/segmentation/`。保存压缩二值掩膜、几何、版本、代码 hash 和审核来源；不复制 CT，不保存自由文本或患者姓名。
- `records/`：与掩膜及元数据一起提交的不可变变更；`blobs/`：内容寻址的压缩快照；`reviews/`：明确人工参考审核；`runs/`：隔离候选及实际评测摘要。
- 通用 artifact 下载入口拒绝整个 `learning/` 目录。摘要接口要求原有病例 view 权限，参考审核要求 review 权限。MCP 服务不能提交人工审核。
- 样本、审核和试算按创建样本起 **180 天**保留；到期后禁止继续引用，由现有后台保留期任务清理。无引用的压缩快照也会清理；正式 CT 与掩膜不受影响。病例删除同时删除其学习产物。
- 冻结清单只记录 hash，不复制或延长数据保留期；样本过期后评测会明确拒绝。更长期训练数据的保留需另行定义，不在此处默认开启。
- 原操作日志的 180 天规则不变。

## 模型无关接口

MCP 工具：

- `inspect_segmentation_learning(case_id)`：读取匿名修正摘要和策略白名单。
- `run_segmentation_candidate(case_id, sample_id, strategy_id)`：本机生成隔离候选并在已有人工参考上比较。仅接受内置策略 ID，不接受模型代码、路径、CT 或标签。

这两个工具使接入同一 MCP 的模型能够调用评测链路。现有 Harness 批量编排器也已接入本机确定性步骤：当前分割有新修正时自动试算三种策略；参考审核或策略版本变化后重新对照，相同记录不重复运行。进度区会显示“分割策略副本试算与对照”。这些确定性计算不消耗大模型 token，结果仍不代替人工确认。

本次没有使用真实 API key 做模型端验收，也没有自动训练或替换模型权重。服务/MCP 进程需加载新版代码后才会暴露新工具。

HTTP 路径：`GET /api/cases/{case_id}/segment/learning`，以及同路径下的 `POST /candidate`、`POST /reference`。参考标签不能通过候选端点写入。

## 固定病例集与升级资格

在本机创建显式清单，每行包含 `case_id`、`sample_id`、`split`（development 或 holdout）。这些只是匿名索引；不要把 CT 或身份信息放进清单。

```powershell
.venv/Scripts/python.exe scripts/evaluate_segmentation_learning.py freeze --input <样本清单.json> --output <新冻结清单.json>
.venv/Scripts/python.exe scripts/evaluate_segmentation_learning.py evaluate --input <冻结清单.json> --output <新对照报告.json> --strategy remove_tiny_islands_v1
```

重复样本、未经审核的参考、同一患者混入开发集与留出集、hash/来源变化、空参考均拒绝。算法只获得修正前快照；参考仅由评测器读取。

报告绑定冻结集合、算法和评测器源码 hash。每例检查漏分、误分、连通组件分断/合并及 HD95/最大边界距离，不允许用总体 Dice 掩盖小通道误删。任何留出集退步会阻断资格。仅合成数据也会阻断。

分割报告采用独立 schema，不替代原六项端面/CFD/成本/体验指标报告。`segmentation_readiness` 最多给出“可进入独立审核”；`auto_promotion` 和 `production_eligible` 始终为 false。正式升级仍需独立来源复核、关键气道区域与下游 CFD 验证及明确发布。

## 验证范围

当前测试使用临时合成数组和真实网关权限链，不调用收费模型、不代填真实病例参考、不运行真实 CFD。测试结果记录在 `docs/superpowers/plans/2026-11-06-segmentation-learning-loop.md`。

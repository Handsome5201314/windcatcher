# 鼻腔分割候选接入：第一阶段记录

日期：2026-11-06。范围：本机预训练候选、版本隔离、可见进度、CT 对照与首批工程试跑。没有训练新权重，没有替换默认算法，没有修改鼻孔保护/确认规则，没有发布患者结果或重启公网服务。

## 实现与使用入口

在已导入、已生成基线分割的病例内，展开“分割改进 · 修正记录与试算”，使用“生成 AI 候选”。完成后 CT 显示可切换“当前结果 / 原主鼻腔（冻结） / AI 候选 / 增删差异”。绿色是新有旧无，红色是旧有新无，均不代表正确与错误。“跳到差异最多处”同步定位三个视图。编辑正式掩膜时自动退出候选预览。

本次 UI 在隔离的合成病例服务中通过桌面及 390px 手机宽度验收。它验证点击、真实 HTTP 路由、状态轮询、三视图 PNG、取消与原掩膜不变；推理部分使用确定性的测试 fixture，不冒充真实模型精度。真实模型集成另见下表。公网运行进程尚未切换，不能把开发文件已修改当作线上 API 已生效。

HTTP：`/api/cases/{case_id}/segment/models`。GET 需 view，POST 需 edit；状态与切片需 view，取消需 edit。未知模型、额外路径、布尔版本、过期输入被拒绝。MCP 只提供 inspect/start/status/cancel，不开放切片、采纳、人工审批。使用既有本机 MCP 身份及病例授权。

候选保存到病例的 `learning/segmentation_models/model-…/`，包含冻结 baseline、原多类 labels、二值 candidate、状态、输入 hash、耗时及实际 GPU 内存统计。二值结果只合并右鼻腔 1、左鼻腔 2、咽部 3，排除组织 4。候选未经过旧身体包络清理，也不会写入正式 mask。目录复用 180 天保留与病例删除边界。

耗时为 worker 内记录的推理/预处理/回写区段，不含全部排队及控制器校验时间；显存是 PyTorch 最大已分配内存，不是整张显卡总占用。

5 例均成功输出非空候选，原网格 shape、spacing、origin、direction 校验通过；每例三平面差异 PNG 均可渲染。第 3、4 例新旧区域重叠很少，是优先复核项。当前只能说明范围差异大，不能认定旧算法错误或新模型正确。连通块数量也不能直接等同于断裂数量。

受限 checkpoint 加载版本对首例复跑成功，正式文件不变；新旧两次候选有 2 个体素差异。当前 GPU 推理未开启全确定性算法，不宣称逐体素可重复或把微小数值波动称为“学习进步”。

私有逐例清单和 hash 证据位于 `.local-models/evaluations/stage1-evaluation-20261106.json`、`.local-models/evaluations/stage1-reverification-20261106.json`。其中不保存 CT 正文；真实影像和候选数组始终留在本机病例目录。评测元数据也纳入 180 天清理，病例删除后下一轮清理移除相应报告行。

## 模型与环境

- 来源：SlicerUpperAirwaySegmentator，固定源 commit `6313dcbcf53db2e0d9331d7c7850a235d93b88c0`，release `v1.1.0`，`Dataset001_Airways_Fink.zip`。
- 压缩包：232485348 bytes；SHA-256 `a58b20100db3a99a6e7a630c9655aa4ee9ffaddbda77a8c0649e311f0092a8f1`，与官方 digest 相符。
- 独立环境 `.venv-segmentation`：Python 3.10.11 / PyTorch 2.6.0+cu124 / nnunetv2 2.6.2，GPU RTX 3090。解析后的依赖记录在 `requirements-segmentation.lock.txt`。
- 固定 fold 0，PlainConvUNet，严格 state_dict 加载；模型未提供的自定义 loss trainer 不导入，使用 nnU-Net 手工初始化推理网络。
- checkpoint 使用 `weights_only=True`，仅允许包内实际需要的 NumPy scalar/dtype 类型。再次核验本机权重后才加载；不使用任意 pickle 执行模式。
- GPU 推理失败时不静默切换为 CPU 结果累积；失败仍为失败。空分割不生成可用候选。
- 非等距且旋转的合成体通过真实 GPU/权重运行，模型返回空前景并被正确拒绝；这仅证明运行与几何/错误路径，不证明解剖能力。
- 仓库代码许可为 Apache-2.0；权重独立分发/商业授权还需确认。本阶段本机评测，不打包分发权重。

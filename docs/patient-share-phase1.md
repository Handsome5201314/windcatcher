# 患者专属只读分享：第一阶段

## 产品边界

团队继续在研究工作台中导入已授权病例、人工复核掩膜、建立 CFD 算例并计算。正式患者发布仍要求当前结果通过 check_result_gate() 的数值、网格敏感性和工程复核，且团队填写发布审核说明。另设独立的未验证测试分享，只用于患者本人核对链接、访问码和页面显示，不把任何检查项改成通过。两类链接都只显示固定版本三维气流快照；不提供诊断、病变标注、治疗建议、原始 CT、病例报告或研究接口。患者自助上传与全自动发布尚未实现。

## 使用流程

1. 团队登录云端研究工作台，在左侧导航打开「患者分享管理」，从已有病例列表选择病例并读取记录。
2. 每次人工修改或质控后，登记阶段、动作与原因；不要在原因中写姓名、电话、病历号等身份信息。
3. 完成掩膜确认、CFD 求解与全部工程闸门后，填写审核人、至少 10 字的审核说明，设置 1–30 天有效期，点击「审核并生成链接」。当前工作台仍使用共享登录，审核人姓名为人工填写，后续真实多人成员审计需改为个人账号。
4. 链接与独立访问码仅在生成时显示一次；团队核对接收人后，分别交付。患者打开链接、输入访问码，即可查看固定版本。管理页可撤销分享；病例删除前也会撤销其全部分享。
5. 若仅需与患者本人测试访问流程，可在「患者测试分享」填写操作人与目的，确认患者已同意接收未验证测试结果，再点「生成未验证测试链接」。该入口要求掩膜已确认、求解已结束、当前可视化已就绪；不要求数值和工程闸门通过。链接仅有效 24 小时，可撤销，患者页持续显示未验证警示。测试成功不代表正式发布条件通过。

### CFD 复核入口

公网研究工作台左侧现有「CFD 复核」，患者分享管理的发布条件下也有「前往 CFD 复核」。选择病例后，页面显示当前算例运行编号、证据指纹和自动数值检查；「复制匿名复核摘要」只包含匿名病例编号、运行编号和检查摘要。页面可登记粗/中/细三网格对比数据、去标识报告编号及工程师意见。记录存于该病例的 review_evidence.sqlite3（不随 CFD 目录重建删除），以 SHA-256 绑定 run_status.json、求解日志、网格缓存和求解字典，并记录网格、流场和后处理文件的路径、大小与修改时间；重算或修改这些源文件后旧记录会标为过期。

**登记不等于通过**：外部网格数据和工程师身份目前无法由共享团队账号独立核实，页面不提供自我批准按钮。记录不会改写 run_status.json 的验证字段，不会放宽残差或绕过 check_result_gate()。数值未收敛、未完成独立网格研究或缺真实工程师签核时，患者发布保持禁止。团队须在其授权资料库保留去标识原始报告，并在后续建立可核验的个人审核身份和独立算例证据链。

## 数据边界与接口

- 研究侧的计算产物仍以 cases/<case_id>/ 和原有状态文件为准。分享数据单独保存在被 Git 忽略的 .local-shares/（云端可配置 WINDCATCHER_SHARE_DIR，镜像默认 /data/shares），含 SQLite 审核/访问记录和不可变 JSON 快照；不存患者姓名或联系方式。患者身份与病例的对应关系应由团队在其授权的业务系统中保管，不能靠公开链接推断。
- 每次人工处理记录附带当时输入文件的 SHA-256；分割纠错记录还把该时点的掩膜复制到病例内的 review_versions/，供后续对照，病例删除时一同删除。发布记录附带输入版本哈希、CFD 参数摘要、阶段状态、结果签名、闸门摘要、审核者与审核说明。上游重算不会改动旧快照。患者快照只含渲染所需的坐标、网格、速度、压力和单位字段，剔除原始结果中的 source、metadata 和未知嵌套字段。
- 团队接口：GET/POST /api/cases/{case_id}/review-events；GET/POST /api/cases/{case_id}/cfd-reviews；GET/POST /api/cases/{case_id}/shares；POST /api/cases/{case_id}/shares/test；POST /api/cases/{case_id}/shares/{share_id}/revoke。均须云端工作台登录，写入还受同源检查保护。测试标记与真实闸门状态记录在分享审计摘要中。
- 患者接口：GET /share/{token}、POST /share/{token}/unlock、GET /share/{token}/model。访问码经 PBKDF2 加盐哈希保存，链接令牌仅保存 SHA-256；模型请求还需绑定该分享的短时 HttpOnly Cookie。链接失效或撤销后不能再读取模型。访问记录只存带密钥哈希的客户端地址，不存原始 IP。

## 验收与上线限制

合成病例测试覆盖：闸门未通过禁止发布、链接与访问码分离、病例 A/B 隔离、过期/撤销、旧版本固定、原始数据与研究 API 不暴露、错误码限速。测试入口为 tests/test_patient_shares.py 与 tests/test_cloud_access.py。

2026-10-30 已将该代码接入原本机公网反代，并恢复任务计划程序守护。公网入口通过 HTTPS 与域名证书检查，匿名研究请求仍受 HTTP Basic 保护；患者路由只绕过 Basic，仍需高熵链接、独立访问码和短时会话。未发布任何真实病例链接，尚未完成真实病例验收；魔搭创空间未在本次重部署。正式向患者发放前，必须取得使用及分享授权，由团队核对发布对象，并落实本地分享库备份、删除策略、反代日志中令牌路径的脱敏以及法规与数据保护审查。代码中的免责声明不能替代这些工作。

2026-10-31 公网研究入口改为单层应用登录，读取独立的 `WINDCATCHER_PUBLIC_*` 凭证，Caddy 已移除 HTTP Basic；魔搭仍使用 `WINDCATCHER_CLOUD_*`。患者分享令牌、访问码和短时会话未改。公网 smoke 已验证匿名病例接口受保护、魔搭凭证不签发公网会话、患者无效链接不泄露模型；真实病例分享仍未验收。

2026-10-31 新增真实病例的未验证测试分享：仅 24 小时、独立访问码、可撤销，患者页有明显警示；正式发布闸门不变。公网本机 Uvicorn 已关闭含令牌路径的访问日志；反代配置没有本站专用 access log。正式发送前仍需核对患者本人及其知情同意，并检查实际部署环境的日志与备份策略。

这些版本、掩膜与纠错记录是后续测量误差和制作验证集的基础；收集 30–50 例本身不会让系统自动学会分割、建网格、求解与审核。后续应逐环节统计人工介入率与失败原因，再决定哪些步骤可自动化，患者发布仍需单独审核。

2026-10-31 患者手机页按实际模型几何和屏幕宽高自动取景，患者可点击「回正视角」。新增约 60 秒自动导览：全程显示气道和运动粒子，前段强调形态、后段强调固定计算工况下的气流；触摸模型会暂停导览，支持继续、重播和手动探索。减少动态效果的系统设置下不自动播放。粒子循环不是实时呼吸，导览不提供健康基准对比、异常判定或诊疗建议；未验证测试分享仍保留原警示与时效、访问控制。

2026-11-01 患者页新增随速度／压力切换的色标、低高端数值与单位解释。色标直接采用渲染器的颜色节点，并转换到显示色彩空间；颜色范围取当前模型，不是跨病例或正常参考范围。患者模型接口先校验不可变快照哈希，再仅使用该分享发布时保存的有效空气密度，将运动学压力乘以密度换算为 Pa；壁面、边界面、切片、流线和色阶范围一起换算。原始快照及其哈希不改写，后续病例参数不参与旧分享的换算。原单位已为 Pa 时不再换算；缺少有效密度时保留 m²/s² 并在页面明确说明；换算得到非有限值时返回可定位的 503 错误。没有新增患者字段，也不改变正式发布闸门、测试警示、访问码或链接时效。

浏览器回归入口：用已安装 Playwright 的 Python 运行 tests/patient-view-browser-smoke.py。默认仅使用合成模型、临时本机 HTTP 服务和真实 WebGL 渲染；覆盖 320／390 像素竖屏、手机横屏及桌面、色标切换、旧单位说明、五个导览角度、回正居中和横向溢出。可用 --model 指定已经授权且去标识的患者展示快照，只用于本机复测，不读取 CT、不启动 CFD；截图和摘要保存在被忽略的 .local-public/legend-ui-smoke/。
